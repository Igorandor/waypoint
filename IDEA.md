# Waypoint — original project idea

A maintenance procedure needs to remember what it changed and what still needs restoring. Waypoint records the starting state of an application or task schedule, guides each step and keeps unfinished restoration work visible after a restart. Read-only procedures collect observations without changing configuration.

Created for the [InterSystems management portal contest](https://openexchange.intersystems.com/contest/48). This document describes this project's own motivation; it is not a claim to have implemented a particular InterSystems Ideas Community Opportunity or earned that bonus.
